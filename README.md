# shareit

隐私优先的家庭图片 / 视频分享应用。

## 产品概念

- **隐私保护机制**：分享内容前需要授权确认；分享不是即时送达，而是留出「反悔窗口」的延时确认，
  确保子女与长辈之间的隐私安全。
- **角色体系**：区分「子女」与「长辈」角色，支持按角色选择性分享（某些内容只想给长辈看）；
  涉及形象保护的内容增加额外的确认 / 授权过滤层。
- **存储模式**：

| 模式 | 费用 | 特点 |
|------|------|------|
| 免费模式 | 免费 | 内容有到期时间，到期后自动失效 |
| 永久存储模式 | 需会员订阅 | 内容永久保存 |

- 落地页 / 官网：仓库 `shareit-landing`
