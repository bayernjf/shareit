# 技术栈 — shareit

更新时间：2026-09-09

## 状态：⚠️ 尚未选型（仓库目前只有 `handoff.md`，无任何代码）

ShareIt 是家庭图片 / 视频分享应用，核心是解决子女与长辈之间分享内容的隐私问题：
分享前授权确认 + 延时送达（给分享者「反悔窗口」），区分「子女 / 长辈」角色按角色选择性分享，
涉及形象保护的内容再加一层确认过滤。

当前进度：产品概念已确认，技术架构与数据模型待设计（见根目录 `handoff.md`）。

## 待决策项（选型时要给出结论并回填本文件）
| 维度 | 待定问题 |
|---|---|
| 端形态 | 移动端优先还是 Web？长辈端是否考虑小程序 / 极简 H5 |
| 前端框架 | 待选（跨端方案 vs 原生） |
| 后端与数据库 | 待选；需承载用户、角色、家庭组、分享内容、确认流程、会员 |
| 媒体存储 | 图片 / 视频存储与 CDN，含到期清理（免费模式）能力 |
| 延时确认机制 | 定时任务 vs 状态机 + 惰性过期，需保证「反悔窗口」可靠 |
| 会员与支付 | 免费（到期失效）/ 永久存储（订阅）两档的计费与到期策略 |
| 隐私合规 | 授权记录留痕、撤回分享、内容删除的传播范围 |

## 约束（来自产品概念，选型必须满足）
- 隐私优先：内容分享前必须显式授权，且支持反悔。
- 角色体系是一等公民：「子女 / 长辈」不是展示标签，而是权限与可见范围的一部分。
- 内容生命周期有两档：到期失效（免费）/ 永久（会员），存储与清理策略要能支撑。
